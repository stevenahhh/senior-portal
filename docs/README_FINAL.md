## 🚀 빠른 시작

### 1. 서버 실행

```powershell
# 터미널 1 - API 서버
cd c:\Users\steve\Desktop\welfare
bun src/server.ts

# 터미널 2 - 프론트엔드
bun dev
```

### 2. 접속

- **일반 사용자**: http://localhost:3000
- **관리자 로그인**: 헤더의 "관리자 로그인" 클릭

### 3. 관리자 로그인 테스트

**테스트 계정:**
- 📧 **이메일**: `admin@center1.or.kr` 또는 `admin@center2.or.kr`
- 🔑 **비밀번호**: `password`

## 🎯 주요 기능 데모

### 프로그램 등록하기

1. **로그인**
   ```
   이메일: admin@center1.or.kr
   비밀번호: password
   ```

2. **"+ 프로그램 등록" 클릭**

3. **정보 입력**
   ```
   프로그램명: 건강 요가 교실
   설명: 초보자를 위한 요가 프로그램
   유형: 신체
   대상: 어르신
   일정 유형: 반복 일정
   시작 일시: 2025-10-20 10:00
   종료 시각: 12:00
   반복 규칙: FREQ=WEEKLY;BYDAY=MO,WE;COUNT=8
   무료: 체크
   상태: 게시
   ```

4. **"등록하기" 클릭**

5. **대시보드에서 확인**

### 프로그램 수정하기

1. 대시보드에서 프로그램 카드의 **"수정"** 버튼 클릭
2. 정보 수정
3. **"수정 완료"** 클릭

### 프로그램 삭제하기

1. 대시보드에서 프로그램 카드의 **"삭제"** 버튼 클릭
2. 확인 대화상자에서 **"확인"** 클릭
