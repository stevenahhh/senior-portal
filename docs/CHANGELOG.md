## 🚀 사용 방법

### 상세 페이지 확인하기

1. **프로그램 상세 보기**
   ```
   1. 메인 페이지에서 "프로그램 찾기" 선택
   2. 관심있는 프로그램 카드 클릭
   3. 상세 정보 확인
      - 일정 및 장소
      - 대상 및 조건
      - 신청 방법
      - 접근성 정보
   4. "← 목록으로 돌아가기" 클릭하여 복귀
   ```

2. **복지관 상세 보기**
   ```
   1. 메인 페이지에서 "복지관 찾기" 선택
   2. 복지관 카드 클릭
   3. 상세 정보 확인
      - 연락처 정보
      - 운영 시간
      - 접근성 시설
      - 진행 중인 프로그램 목록
   4. "← 목록으로 돌아가기" 클릭하여 복귀
   ```

## 🎨 UI/UX 개선사항

### 상세 페이지 디자인
- **카드 기반 레이아웃**: 정보를 논리적 그룹으로 구성
- **아이콘 사용**: 시각적 인지성 향상
- **색상 코딩**: 
  - 파란색: 대상 정보
  - 보라색: 프로그램 유형
  - 초록색: 무료/접근성
  - 주황색: 유료
- **반응형 그리드**: 모바일/태블릿/데스크톱 최적화

### 접근성 정보 시각화
- 이모지 아이콘으로 직관적 표현
- 색상 + 텍스트 조합으로 정보 전달
- 스크린 리더 친화적 마크업

## 📱 테스트 시나리오

### 상세 페이지 테스트

```powershell
# 1. 서버 실행 확인
bun src/server.ts  # 터미널 1
bun dev            # 터미널 2

# 2. 브라우저에서 테스트
http://localhost:3000

# 3. 테스트 순서
1. 프로그램 카드 클릭
   → 상세 페이지 표시 확인
   → 일정 정보 형식 확인
   → 돌아가기 버튼 작동 확인

2. 복지관 카드 클릭
   → 상세 페이지 표시 확인
   → 접근성 정보 표시 확인
   → 프로그램 목록 표시 확인
   → 돌아가기 버튼 작동 확인

3. 반응형 테스트
   → 개발자 도구로 모바일 뷰 확인
   → 그리드 레이아웃 변화 확인
```

## 🔧 기술적 개선사항

### 컴포넌트 구조
```
components/
├── CenterCard.tsx       # 복지관 카드 (클릭 가능)
├── ProgramCard.tsx      # 프로그램 카드 (클릭 가능)
├── CenterDetail.tsx     # 복지관 상세 페이지 ✨ NEW
├── ProgramDetail.tsx    # 프로그램 상세 페이지 ✨ NEW
└── SearchBar.tsx        # 검색 바
```

### 상태 관리
```typescript
// 상세 뷰 상태
type DetailView = 
  | { type: 'center'; id: string } 
  | { type: 'program'; id: string } 
  | null;

// 조건부 렌더링
if (detailView) {
  return detailView.type === 'center' 
    ? <CenterDetail /> 
    : <ProgramDetail />;
}
```

### RRULE 파싱
```typescript
// 반복 일정 규칙 해석
FREQ=WEEKLY;BYDAY=MO,TH;COUNT=16
→ "매주 월, 목요일 (총 16회)"

FREQ=DAILY;COUNT=30
→ "매일 (총 30회)"
```

## 🐛 알려진 이슈 및 해결 방법

### API 연결 오류
```
문제: "Failed to fetch" 에러
해결: API 서버(bun src/server.ts)가 실행 중인지 확인
```
