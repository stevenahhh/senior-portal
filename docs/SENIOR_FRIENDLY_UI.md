# 🎯 50대 이상 사용자를 위한 UI/UX 가이드

본 사회복지 포털은 **50대 이상의 사용자**를 주요 타겟으로 설계된 접근성 높은 웹 애플리케이션입니다.

## 🔍 주요 개선 사항

### 1. **큰 글씨 (Large Typography)**

#### 기본 글꼴 크기
- **본문**: 18px → 1.125rem (기존 대비 150% 증가)
- **제목 H1**: 2.5rem (40px) - 명확하고 눈에 잘 띔
- **제목 H2**: 2rem (32px)
- **제목 H3**: 1.5rem (24px)
- **버튼/입력**: 1.25rem (20px)

#### 줄 간격 (Line Height)
- 본문: 1.8 (180%)
- 제목: 1.3-1.4
- **넓은 줄 간격으로 가독성 향상**

### 2. **큰 터치 타겟 (Large Touch Targets)**

#### 최소 크기
- **버튼**: 56px 높이 (WCAG 권장 44px 초과)
- **모바일 버튼**: 64px 높이
- **입력 필드**: 56px 높이
- **체크박스/라디오**: 28x28px

#### 여백
- 버튼 패딩: 16px 상하, 28px 좌우
- 카드 패딩: 24px
- 간격: 20-24px (senior-spacing)

### 3. **명확한 시각적 피드백**

#### 호버 효과
```css
button:hover {
  transform: translateY(-2px);
  box-shadow: 0 6px 12px rgba(0, 0, 0, 0.15);
  scale: 105%;
}
```

#### 포커스 표시
- **두꺼운 아웃라인**: 4px (기존 2px 대비 2배)
- **명확한 색상**: 파란색 (#3b82f6)
- **offset**: 4px로 여유 공간 확보

#### 선택 상태
- **배경색 변화**: 파란색 강조
- **그림자 효과**: shadow-lg
- **크기 변화**: scale-105 또는 110%

### 4. **높은 색상 대비 (High Contrast)**

#### 텍스트 대비
- **주요 텍스트**: #111827 (거의 검정)
- **보조 텍스트**: #374151 (진한 회색)
- **배경**: #ffffff (흰색)
- **대비율**: WCAG AAA 수준 (7:1 이상)

#### 상태 색상
- **무료**: 초록색 배경 + 흰색 텍스트
- **온라인**: 파란색 배경 + 흰색 텍스트
- **선택됨**: 진한 파란색 + 그림자

### 5. **이모지 아이콘 활용**

시각적 인지를 돕는 명확한 이모지 사용:
- 🏛️ 복지관
- 📋 프로그램
- 🔍 검색
- 📍 위치
- 💰 무료
- 💻 온라인
- 📞 전화
- 🏢 주소
- 📅 날짜
- 👥 대상
- ♿ 접근성
- 🔄 초기화
- ✓ 확인
- 🚪 로그아웃

### 6. **간단한 레이아웃**

#### 그리드 레이아웃
- **모바일**: 1열
- **태블릿**: 2열 (기존 3열에서 감소)
- **데스크톱**: 2열 (기존 3열에서 감소)
- **간격**: 24px (senior-grid)

#### 카드 디자인
```css
.senior-card {
  padding: 24px;
  border: 2px solid #e5e7eb;
  border-radius: 16px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08);
}

.senior-card:hover {
  border-color: #3b82f6;
  box-shadow: 0 4px 16px rgba(59, 130, 246, 0.15);
  transform: translateY(-2px);
}
```

### 7. **명확한 버튼 텍스트**

#### AS-IS (이전)
- "검색"
- "필터"
- "이전" / "다음"

#### TO-BE (현재)
- "🔍 검색"
- "▼ 필터 열기" / "▲ 필터 닫기"
- "◀ 이전 페이지" / "다음 페이지 ▶"
- "🔄 초기화"
- "✓ 필터 적용"

### 8. **배지 및 태그 강조**

#### 크기
```css
.senior-badge {
  padding: 10px 20px;
  font-size: 1.125rem (18px);
  font-weight: 600;
  border-radius: 20px;
}
```

#### 상태별 스타일
- **프로그램 유형**: 보라색 배경 + 흰색 텍스트
- **무료**: 초록색 배경 + 흰색 텍스트
- **온라인**: 파란색 배경 + 흰색 텍스트
- **편의시설**: 연두색 배경 + 초록색 텍스트

### 9. **로딩 및 상태 메시지**

#### 로딩 스피너
- **크기**: 56x56px (기존 32x32px 대비 증가)
- **두께**: 6px border
- **메시지**: "데이터를 불러오는 중입니다..." (2xl 폰트)

#### 상태 메시지
```tsx
<div className="text-center py-16" role="status">
  <p className="text-2xl font-bold text-gray-600">
    😕 검색 결과가 없습니다
  </p>
  <p className="text-xl text-gray-500 mt-4">
    다른 조건으로 검색해보세요
  </p>
</div>
```

### 10. **폼 요소 개선**

#### 입력 필드
- **크기**: 56px 높이
- **패딩**: 14px 상하, 18px 좌우
- **폰트**: 1.25rem (20px)
- **테두리**: 2px (일반) → 3px (포커스)
- **테두리 색상**: 회색 → 파란색 (포커스 시)

#### 레이블
```css
label {
  font-size: 1.25rem (20px);
  font-weight: 600;
  color: #1f2937;
  margin-bottom: 10px;
  display: block;
}
```

## 🧪 테스트 가이드

### 1. 가독성 테스트
- [ ] 팔 길이 거리(약 50-60cm)에서 글씨가 명확하게 보이는가?
- [ ] 돋보기 없이 모든 텍스트를 읽을 수 있는가?
- [ ] 중요한 정보(가격, 날짜)가 눈에 잘 띄는가?

### 2. 터치 테스트
- [ ] 모든 버튼을 손가락으로 쉽게 탭할 수 있는가?
- [ ] 버튼 사이 간격이 충분한가?
- [ ] 실수로 잘못된 버튼을 누르지 않는가?

### 3. 시각 피드백 테스트
- [ ] 버튼 위에 마우스를 올리면 반응이 명확한가?
- [ ] 클릭 시 상태 변화가 즉시 인식되는가?
- [ ] 현재 선택된 항목이 명확하게 구분되는가?

### 4. 인지 부하 테스트
- [ ] 한 화면에 너무 많은 정보가 있지 않은가?
- [ ] 버튼의 기능이 텍스트만으로 이해되는가?
- [ ] 아이콘과 텍스트가 함께 제공되는가?

## 💡 디자인 원칙

### 1. **명확성 (Clarity)**
- 모호한 아이콘 대신 **이모지 + 텍스트** 조합
- 짧고 명확한 버튼 라벨
- 숫자는 **큰 폰트 + 굵은 글씨**로 강조

### 2. **일관성 (Consistency)**
- 모든 버튼이 같은 최소 높이 유지
- 같은 색상 체계 사용
- 예측 가능한 레이아웃

### 3. **여유 (Spacing)**
- 넉넉한 패딩과 마진
- 요소 간 충분한 간격
- 덜 복잡한 그리드 (2열)

### 4. **피드백 (Feedback)**
- 호버 시 명확한 변화
- 클릭 시 시각적 반응
- 로딩 중 명확한 표시

### 5. **친근함 (Friendliness)**
- 이모지로 시각적 즐거움
- 따뜻한 색상 사용
- 긍정적인 메시지

## 📱 반응형 설정

### 모바일 (<768px)
```css
@media (max-width: 768px) {
  button { min-height: 64px !important; }
  input { min-height: 64px !important; }
  body { font-size: 20px; }
}
```

### 태블릿 (768px - 1024px)
- 2열 그리드
- 터치 최적화

### 데스크톱 (>1024px)
- 2열 그리드 (여유로운 레이아웃)
- 마우스 + 키보드 최적화

## 🔧 적용 방법
